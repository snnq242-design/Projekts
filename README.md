Saskarnes valoda: latviešu
Par projektu
Mācību un prezentācijas projekts Jūrmalas Kauguru vidusskolas vietnei. Tas nav skolas oficiālā vietne un nepārstāv skolas apstiprinātu informācijas sistēmu.
Prezentācijas vietnes adrese: https://spry-azure-nkoubil.tmp.now
Publicētā versija var atšķirties no jaunākajiem lejupielādētajiem avota failiem.
Failu struktūra
index.html — sākumlapa, ziņas un paziņojumi.
info.html — informācija, dokumentu sadaļa, biežāk uzdotie jautājumi, administrācija un kontakti.
kalendars.html — mēneša kalendārs, mēnešu pārslēgšana, klases, notikuma veida un datumu filtri.
kon.html — pieslēgšanās un reģistrācijas demonstrācijas formas.
style.css — kopīgie adaptīvie melnpelēkie stili.
main.js — navigācija, vietnes meklēšana, kalendārs un veidlapu pārbaude.
README.md — projekta apraksts un palaišanas norādes.
LICENSE — autortiesību un izmantošanas nosacījumi.
Palaišana
Ievieto visus sešus vietnes avota failus vienā mapē.
Ja lejupielādētajiem failiem beigās ir .txt, noņem tikai šo pēdējo paplašinājumu, piemēram, index.html.txt pārdēvē par index.html.
Atver index.html pārlūkprogrammā.
Alternatīvi atver projekta mapi ar Visual Studio Code un izmanto Live Server paplašinājumu.
Internets ir vajadzīgs Bootstrap 5, Google Fonts un ārējā attēla ielādei.
Būvēšanas rīki un pakotņu instalēšana šai statiskajai versijai nav nepieciešama.
Tehnoloģijas
HTML5, CSS3, JavaScript, Bootstrap 5.3.3 un Public Sans fonts no Google Fonts.
Iespējas
Adaptīvs izkārtojums datoram, planšetdatoram un tālrunim.
Mobilā navigācija.
Meklēšana vietnes iepriekš sagatavotajā satura rādītājā, tostarp ziņās un kontaktinformācijā.
Meklēšana bez latviešu diakritiskajām zīmēm.
Mēneša kalendārs un notikumu filtri.
Izvēršamas FAQ atbildes.
Klikšķināmi tālruņi, e-pasts un karšu saites.
Pārslēgšanās starp pieslēgšanās un reģistrācijas formu.
Paroles rādīšana un slēpšana.
Reģistrācijas paroles prasību un abu paroļu sakritības pārbaude.
Svarīgi ierobežojumi
Autentifikācija
Pieslēgšanās un reģistrācija ir tikai demonstrācija. Veidlapas neizveido kontus, nepārbauda reālus lietotājus un nesaglabā paroles. Veiksmīga formas pārbaude nenozīmē veiksmīgu autentifikāciju.
Reālai darbībai jāizveido drošs servera vai autentifikācijas pakalpojuma savienojums, sesiju pārvaldība, e-pasta verifikācija un piekļuves tiesību pārbaude serverī. Lietotāja izvēlēta skolotāja loma pati par sevi nedrīkst piešķirt skolotāja tiesības.
Neievieto privātās atslēgas vai īstas lietotāju paroles publiskajā kodā. Neizmanto īstus personas datus demonstrācijas formās.
Saturs
Ziņas un pasākumi ir demonstrācijas saturs, nevis skolas apstiprināti paziņojumi.
Dokumentu sadaļā daļa dokumentu nav pievienota.
Kontakti un administrācijas vārdi pārņemti no skolas oficiālās vietnes. Dažu avotu lapu kājenēs norādīts 2022. gads; informācijas aktualitāte jāpārbauda skolā.
Sākumlapā izmantota skolas ēkas fotogrāfija no oficiālās vietnes: https://kauguruvsk.lv/images/kvs-vidusskola1.png. Fotogrāfijas izmantošanai piemērojamas tās tiesību īpašnieka tiesības.
Burts K ir pagaidu zīme, nevis skolas oficiālais logotips.
Meklēšanas rādītājs ir statisks; mainot saturu, jāatjaunina arī meklēšanas ieraksti.
Kalendārs tālrunī ir ritināms horizontāli; atlasītie notikumi pieejami arī sarakstā.
Paplašināta manuāla pārlūkprogrammu, piekļūstamības un drošības testēšana pirms reālas izmantošanas vēl ir nepieciešama.

Publicēšana
Statiskos failus var ievietot statisku vietņu mitināšanas pakalpojumā. Visām četrām HTML lapām, style.css un main.js jāsaglabā savstarpējais novietojums vienā mapē.
Framer publicētā prezentācija un šī atsevišķu HTML failu versija ir atšķirīgi izvietošanas veidi. Avota failu lejupielāde pati par sevi neatjaunina Framer publisko vietni.
